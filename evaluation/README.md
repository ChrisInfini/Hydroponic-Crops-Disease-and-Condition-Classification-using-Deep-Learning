# Model Evaluation

This folder contains the evaluation script and the metrics/figure from the held-out test run.

- `evaluate_model.py`: reruns evaluation in Google Colab.
- `test_summary.json`: overall test metrics.
- `classification_report.txt` / `.json`: per-class precision, recall, F1-score, and support.
- `class_accuracy.json`: per-class metrics (the `recall` field is the precise class-wise accuracy measure).
- `confusion_matrix.png`: raw-count confusion matrix from the supplied run.

The reported run evaluated 5,947 test images across 30 classes. Ensure the class order used by the test directory matches the class order used to train the model and configure inference.

The normalized confusion matrix is generated by the script, but was not included in the supplied output files used to assemble this package.
